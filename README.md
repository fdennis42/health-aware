# Health Aware

A small installable iPhone web app for tracking headaches, blood pressure, back/shoulder pain, weight and IBS/bowel movements, including medications and actions taken, with trends and a provider report (Print/PDF, shareable report file, CSV, email summary).

All health data is stored only on the device (browser storage). Nothing is sent to this repository or any server.

## Install on iPhone
1. Enable GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.
2. Open `https://fdennis42.github.io/health-aware/` in Safari on the iPhone.
3. Share → **Add to Home Screen**.

The app's Log and Settings screens include full instructions for sending the link from a Mac and moving data between devices.
